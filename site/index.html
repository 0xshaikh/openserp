The Audit Rubric

Weights sum to exactly 100. Every rule is in the source code.

Rule Weight Severity Check
HTTPS_ENFORCED 12 error HTTPS served, HTTP redirects
META_DESC_OK 10 error ≥80% pages, 50-160 chars
TITLE_OK 10 error ≥90% pages, 10-60 chars
LINKS_HEALTHY 10 error ≥90% sampled links return 2xx/3xx
H1_OK 8 error ≥90% pages, exactly one H1
SITEMAP_OK 8 error Parseable sitemap reachable
IMG_ALT_OK 8 warning ≥80% img tags carry alt
CONTENT_LEN_OK 6 warning ≥70% pages have 300+ words
ROBOTS_OK 6 warning robots.txt published, not blocking
REDIRECTS_CLEAN 6 warning No page needs >2 redirect hops
TITLE_UNIQUE 6 warning ≥95% page titles unique
JSONLD_OK 5 warning ≥50% pages emit schema.org JSON-LD
CANONICAL_OK 5 info ≥70% pages declare rel=canonical

Installation

git clone https://github.com/0xshaikh/openserp.git
cd openserp
pip install -e .
View full docs →

Run an Audit

openserp audit https://example.com \
  --max-pages 20 \
  --link-probes 25
View audit docs →

Keyword Research

openserp keywords \
  "seo audit" \
  --count 20
View keyword docs →

Start Dashboard
